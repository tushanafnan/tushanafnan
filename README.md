## Things I Believe About Engineering

> **Fundamentals compound.**

Frameworks change. Languages evolve. Libraries disappear.

The ability to reason about systems, data structures, algorithms, networks, databases, operating systems, and distributed systems remains valuable.

> **A working prototype is not necessarily a good system.**

I care about correctness, observability, maintainability, security, performance, and the reasoning behind engineering decisions.

> **AI should accelerate engineering — not replace understanding.**

Tools such as AI coding assistants are powerful, but blindly accepting generated code creates technical debt faster than it creates software.

The goal is to use AI to **think better and build faster**, while retaining ownership of the underlying engineering decisions.
